ReadyDocs support

Start a document handoff

  1. Set an Android PIN, pattern or password. After restarting your phone, unlock it once before using ReadyDocs.
  2. Open ReadyDocs, tap Unlock owner setup and verify your screen lock.
  3. Import one or more files and select the files to show. Use Enable automatic lock and approve Android’s prompt to use Lock phone and start handoff. For manual locking, use Start selected handoff.
  4. Within one minute, wake the phone without unlocking. If you chose manual locking, turn off the screen first and let Android lock the phone. The viewer ends after three minutes, on unlock or when you leave it.

Turn off automatic lock

Use Disable automatic lock in owner setup or switch off ReadyDocs in Android’s device admin settings. Android may require your PIN, pattern or password after an automatic lock. If Android blocks uninstalling ReadyDocs, turn off its device administrator access first.

The viewer keeps asking you to lock the phone

Wait until Android actually requires authentication before waking the screen. Android’s lock delay and settings such as Extend Unlock can keep the phone unlocked with the screen off. Review those settings if the viewer stays on the waiting screen.

Photograph both sides of a card

Tap Add ID and insurance photos and choose a driver’s license, health insurance card, or car insurance card. Keep all four corners visible. Accept each shot in the camera, then tap Save both sides in ReadyDocs. Use Retake if the text is hard to read. Each pair takes one vault slot.

A file won’t import

Use a readable PDF or image. Each file must be 12 MiB or smaller, and a PDF can have up to 80 pages. If your provider offers an online-only file, make it available to Android’s file picker and try again.

Show the emergency card

Save the card in owner setup. The Set up lock-screen access screen explains how to look for ReadyDocs Emergency in your phone’s lock-screen widget editor. On Android 13 and newer, tap Add Quick Settings tile to open Android’s confirmation. The same screen explains manual tile setup. Tap Show emergency notification to try a quiet shortcut on the lock screen. Android controls whether and where it appears, including on a charging or always-on display. Lock your phone and try the shortcut. The widget and tile open only the emergency card, and some phones require unlocking to use the tile.
