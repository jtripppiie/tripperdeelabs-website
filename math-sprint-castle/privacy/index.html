Math Sprint Castle privacy policy

Effective October 31, 2026. Developer: TripperDeeLabs. This describes the current development build.

Offline game and local progress

The game runs offline and does not require an account. The current Android build has no internet permission and no advertising, analytics or tracking SDK. Math progress, play time, coins, unlocked content, character selection and preferences are stored locally. Clearing app data or uninstalling can erase progress; the game does not provide an online backup account.

Computer practice preview

The watchable computer mode simulates play locally. Its preview time, coins and math answers do not change the player's saved progression. It does not send play data to TripperDeeLabs.

Purchases

The current development build does not process real-money purchases. Its All Access option is a preview. This policy will be updated before changes to payment or data handling are released.

Children and support

The game has no chat, public profiles or personal-information form, and does not request camera, microphone, contacts or location access. A parent or guardian can contact TripperDeeLabs@gmail.com for support. Emails contain whatever address, message and attachments the sender chooses to provide; please do not include sensitive information about a child. Support correspondence is used to respond to the request and is not sold. Contact the same address to request its deletion.

This website

This app policy is separate from the website privacy policy, which describes this site's optional analytics.
