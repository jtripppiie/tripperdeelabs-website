Mock Location support

Setup help and practical limits for Android's mock-location capability.

Choose the mock-location app

  1. Enable Android Developer options.
  2. Open Select mock location app.
  3. Select Mock Location: Fake GPS.
  4. Return to the app, choose a point, and start the location.

The location does not appear elsewhere

  • Confirm this app remains selected as Android's mock-location app.
  • Confirm the session is active and its notification is visible.
  • Check whether the other app rejects mock locations or uses Wi-Fi, cellular, IP address, account history, or another signal.
  • Stop other location-changing tools so they do not compete for the test provider.

Location jumps or flips

Stop the session, close other mock-location tools, verify the selected mock-location app in Developer options, and start a single static test point again. A third-party app may also be combining GPS with other location signals.

Contact

Email TripperDeeLabs support. Include the phone model, Android version, app version, and a description of what happened. Do not send private coordinates.
