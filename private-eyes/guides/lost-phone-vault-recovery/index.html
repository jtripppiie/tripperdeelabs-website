What happens to a photo vault when you lose your phone?

Understand Private Eyes device-bound storage, pattern loss and the limits of recovery before storing irreplaceable files.

Reviewed October 26, 2026 · TripperDeeLabs

Private Eyes currently cannot recover a vault from a lost phone. It stores encrypted files locally and uses device-bound key protection. There is no account, recovery phrase, cloud backup or developer-held recovery key.

Different problems, different outcomes

  • Lost or broken phone: a replacement phone does not automatically receive a usable Private Eyes vault.
  • Forgotten pattern: there is no reset service that restores access to the encrypted contents.
  • Uninstalling or clearing app data: this can permanently remove the local vault and access material.
  • Removing or forcibly resetting the screen lock: this can invalidate the device key and make the vault inaccessible.

Plan before removing your originals

Keep a separate copy of irreplaceable material in a location you trust. Private Eyes can export readable copies, but those exports are unencrypted and outside the vault’s protection. Decide how to protect that destination separately. Copying the app’s encrypted files alone is not a supported portable backup.

If the phone still works

  1. Keep the existing installation and device security intact.
  2. If you can unlock the vault, export important files to a trusted destination.
  3. Open the exported files and verify they are usable before changing phones or removing anything.
  4. On another phone, import those copies into a newly configured vault, then review the intermediate copies.

If a file will not open

Do not clear app data, reinstall or delete the item to troubleshoot. A failed preview may reflect an unsupported format. Try exporting the original. If integrity verification fails, preserve the stored file and contact support with a description of the error; do not send private photos or access secrets. Support cannot bypass encryption or reconstruct missing keys.

This limitation is part of the current product, not a claim that all vault apps behave this way. When comparing apps, check whether backup exists, whether it is encrypted and whether recovery has been tested on a different device.
